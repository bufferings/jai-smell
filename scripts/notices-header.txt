Bun runtime, embedded in the jai-smell binary by "bun build --compile"
https://github.com/oven-sh/bun
===========================================================================

The jai-smell binary contains the Bun runtime. Bun itself is MIT-licensed.
Bun statically links JavaScriptCore and WebKit, which are licensed under the
GNU Library General Public License version 2 (LGPL-2). The source code of
the JavaScriptCore and WebKit used by Bun is available at:
https://github.com/oven-sh/WebKit

To run jai-smell with a modified version of these libraries:

1. Build Bun with the modified libraries by following the instructions in
   Bun's LICENSE.md, which is reproduced below.
2. Get the jai-smell source code, which is the complete application in a
   form that can be relinked, from https://github.com/bufferings/jai-smell
3. With the Bun built in step 1, run the following in the jai-smell source
   tree to produce a new jai-smell binary:
     bun install --frozen-lockfile
     bun run build

The version of Bun used to build a release is recorded in the .bun-version
file of the jai-smell source code at the release tag.
